# C Language Studies

This repository was created to store my exercises, challenges, and practical studies during my C programming learning journey.

## Repository Structure

Each folder contains the solution to a specific exercise proposed in class:

* **Exercise 4:** Calculation of the perimeter, surface area, volume, and space diagonal of a rectangular cuboid.
* **Exercise 6:** Calculation of the nth term of an Arithmetic Progression (AP).
* **Exercise 7:** Calculation of the nth term of a Geometric Progression (GP).
* **Exercise 8:** Conversion of a specific time into elapsed minutes and seconds since the beginning of the day.
* **Exercise 9:** Calculation of how many minimum wages are contained within a given salary.

## How to run the code
To compile and run any of the exercises, you can use GCC in your terminal:

```bash
gcc main.c -o program -lm
./program
```

Note: The -lm flag is required for exercises that utilize the math.h library.
